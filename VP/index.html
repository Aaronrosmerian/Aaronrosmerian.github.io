Optimasi Performa Tinggi & Mode Cepat HP

Mengapa Tombol "Mode Cepat HP" Bisa Instan di Android & iPhone?
  • Melewati Penyalinan Cache Galeri Android: Memakai filter dokumen biner khusus (tanpa video/*) sehingga Android langsung membuka Sistem File / Dokumen dan memberikan pointer memori langsung (Zero-Copy) tanpa menyalin video bergiga-giga ke folder sementara.
  • Mencegah Auto-Transcoding iOS (iPhone/iPad): Menghentikan Safari/iOS mengonversi ulang video .MOV (HEVC 1080p/4K) menjadi H.264 sebelum diputar.
  • Tips Tambahan: Di menu File HP yang terbuka, pilih dari folder Penyimpanan Internal / Download / DCIM (hindari memilih lewat pintasan aplikasi Galeri/Google Photos).
Mengapa Pemutaran 720p / 1080p / 4K Bebas Lag?
  • Zero Blur Compositing: Semua efek backdrop-filter: blur di atas kanvas video telah dihapus agar GPU tidak terbebani melakukan penyalinan ulang piksel pada resolusi 1080p/4K.
  • Zero-Reflow Progress Bar: Menggunakan akselerasi GPU transform: scaleX() dan menghentikan mutasi DOM otomatis saat kontrol disembunyikan.
  • Fast-Seek Engine: Saat menggeser timeline video ber-bitrate tinggi, pemutar membatasi (*throttle*) frekuensi dekode agar tidak macet.
